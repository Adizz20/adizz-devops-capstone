# Adizz

Adizz is a Travel & Booking Management System built as a DevOps Final Capstone project.

## Project

The application will provide a web-based interface for managing travel bookings.

## Technology Stack

- React
- FastAPI
- PostgreSQL
- Docker
- GitHub Actions
- GitHub Container Registry
- Trivy
- Terraform
- AWS EKS
- Kubernetes
- Helm
- Prometheus
- Grafana
